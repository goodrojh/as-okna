# Приём заявок: Google Таблица + почта + WhatsApp

Каждая заявка с сайта попадает сразу в три места:
1. строка в Google Таблице;
2. письмо на **as.george@mail.ru**;
3. сообщение в WhatsApp на **+7 961 440-00-14**.

Всё делает один бесплатный скрипт Google Apps Script внутри таблицы ([google-apps-script.gs](google-apps-script.gs)).

## 1. Таблица и скрипт (5 минут)

1. Откройте <https://sheets.new> под своим Google-аккаунтом, назовите таблицу «Заявки AS·окна».
2. Меню **Расширения → Apps Script**.
3. Удалите всё в редакторе и вставьте содержимое файла `google-apps-script.gs`. Нажмите 💾.
4. Сверху выберите функцию **testLead** → **Выполнить** → разрешите доступ (Google спросит про таблицу, почту и внешние запросы — это нормально).
   В таблице появится лист «Заявки» с тестовой строкой, на почту придёт тестовое письмо.
5. **Развертывание → Новое развертывание** → тип «Веб-приложение»:
   - Выполнять как: **Я**
   - У кого есть доступ: **Все**
6. Нажмите «Развернуть» и скопируйте **URL веб-приложения** (вида `https://script.google.com/macros/s/…/exec`).
7. Пришлите этот URL — он вставляется в сайт (`LEAD_ENDPOINT`), после чего формы начнут отправлять заявки.

## 2. WhatsApp (2 минуты)

1. Добавьте в контакты телефона с WhatsApp номер **+34 644 99 26 98** (сервис CallMeBot).
2. Отправьте на него в WhatsApp сообщение: `I allow callmebot to send me messages`
3. В ответ придёт **apikey** (несколько цифр).
4. В Apps Script вставьте его в строку `const CALLMEBOT_APIKEY = '';` → 💾 →
   **Развертывание → Управление развертываниями → ✏️ → Версия: новая → Развернуть** (URL не меняется).

> CallMeBot — бесплатный сервис для уведомлений на собственный номер. Если когда-нибудь он станет недоступен,
> заявки всё равно продолжат приходить на почту и в таблицу.

## Защита от спама

Скрипт принимает только номера из 11 цифр, отбрасывает «мгновенные» отправки ботов
и не дублирует заявку с одного номера чаще раза в 2 минуты.
